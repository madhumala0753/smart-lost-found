# Smart Lost & Found

A zero-cost, front-end college project prototype.

## Files
- `index.html` — pages and UI
- `style.css` — responsive design
- `script.js` — search, filters, reports, demo login and local storage

## Run
Double-click `index.html` to open it in a browser.

## Important
This version uses browser `localStorage`, so data is saved only in that browser/device. Login is a demo, not real authentication. For a production system, connect a backend/database and real authentication.

## Free publishing
You can publish these files with GitHub Pages:
1. Create a GitHub account.
2. Create a new public repository, e.g. `smart-lost-found`.
3. Upload `index.html`, `style.css`, and `script.js`.
4. Repository Settings → Pages.
5. Choose "Deploy from a branch", select `main` and `/root`.
6. Save and wait for the Pages URL.
